# Cartera de oportunidades

Copiá este archivo a `design/opportunities.md` del proyecto. Antes de agregar o priorizar una fila, leé el estado
vigente, los pendientes, el feedback y las fuentes canónicas que indique el `CLAUDE.md` del proyecto. Un pendiente
documentado no es automáticamente la próxima prioridad. Cuando se abra un expediente, enlazalo.

| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| OP-01 | | | | | | | | | observada | pendiente |

Estados: `observada`, `investigar`, `activa`, `esperando evidencia`, `resuelta`, `descartada`. Registrá por qué se
descarta o posterga una oportunidad material. Las decisiones provisionales con una señal futura también tienen fila:
fecha de revisión, responsable, señal y expediente. Si se cumple la condición de cambio, reabrí la decisión anterior
antes de priorizar una solución nueva. No inventes datos ni conviertas un supuesto de dominio o comercial en hecho.
